Question 1: Understanding R

In your own words, explain what R is and why it has become such a common tool for data analysis. Name at least two features that set it apart from spreadsheet software.

R is a programming language that was made mainly for statistics and data analysis. It has become popular because it’s free and open source, anyone can download it and start using it without paying for a license. It also has a huge number of packages people have written that add extra functions, like ggplot2 for plots, so you usually don’t have to build everything from scratch.

Compared to a spreadsheet like Excel, R lets you write code that you save and run again later. If your data changes you just rerun the script instead of redoing all the clicking by hand, which also makes it easier for someone else to check your work. It can also handle much bigger datasets than a spreadsheet can without slowing down.

Question 2: Basic Programming

Using the penguins data from the palmerpenguins package, compute the mean, median, standard deviation, and quartiles of body mass. Briefly describe the distribution, citing the values you compute.

First I used summary() to get an overview of body mass.

summary(penguins$body_mass_g)
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max.     NAs 
   2700    3550    4050    4202    4750    6300       2

summary() already shows the quartiles but the question asked for them specifically so I also ran quantile(), plus sd() for the standard deviation. There are a couple missing values in body mass so I had to add na.rm = TRUE, otherwise these come back as NA.

# sd(penguins$body_mass_g)   this was just giving NA
mean(penguins$body_mass_g, na.rm = TRUE)
[1] 4201.754
sd(penguins$body_mass_g, na.rm = TRUE)
[1] 801.9545
quantile(penguins$body_mass_g, na.rm = TRUE)
  0%  25%  50%  75% 100% 
2700 3550 4050 4750 6300

The mean body mass is 4201.8 grams and the median is 4050 grams, so they are pretty close. The standard deviation is about 802 grams. The quartiles are 3550 (25%) and 4750 (75%), and the masses range from 2700 up to 6300 grams. Overall the distribution looks pretty normal to me, most penguins are between about 3550 and 4750 grams with a few bigger ones at the top end.

Question 4: Species Comparisons

Compute the average body mass and bill length for each combination of species and sex, excluding penguins where sex is missing. Which species is largest, and is the male/female difference similar across the three species?

species_sex = penguins %>%
  group_by(species, sex) %>%
  summarise(avg_mass = mean(body_mass_g, na.rm = TRUE),
            avg_bill = mean(bill_length_mm, na.rm = TRUE))
