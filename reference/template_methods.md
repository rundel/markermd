# Methods for Markermd Template Classes

Console methods for the S7 template classes:
[`print()`](https://rdrr.io/r/base/print.html) for templates, questions,
node selections and template metadata, and
[`length()`](https://rdrr.io/r/base/length.html) for templates (the
number of questions) and node selections (the number of selected node
ids). Validation lives in the class validators and serialization in
[`read_template_yaml()`](https://rundel.github.io/markermd/reference/read_template_yaml.md)
/
[`write_template_yaml()`](https://rundel.github.io/markermd/reference/write_template_yaml.md).
